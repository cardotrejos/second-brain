# Building a Second Brain - PARA System Guide

## The PARA Structure

```
0 - Inbox/     <- Capture everything here first
1 - Projects/  <- Active work with deadlines
2 - Areas/     <- Ongoing responsibilities
3 - Resources/ <- Reference material
4 - Archives/  <- Completed/inactive items
```

---

## Quick Decision Tree

When organizing a note, ask yourself:

1. **Is this actionable right now?** → `1 - Projects`
2. **Is this an ongoing responsibility?** → `2 - Areas`
3. **Is this useful reference material?** → `3 - Resources`
4. **Is this done or no longer relevant?** → `4 - Archives`
5. **Not sure yet?** → Keep in `0 - Inbox`

---

## Folder Definitions

### 0 - Inbox
Quick capture zone. Process weekly during your review.
- New ideas
- Unsorted notes
- Things to read/watch
- Quick thoughts

### 1 - Projects
Short-term efforts with a **defined endpoint**.
- Has a deadline or goal
- Can be "completed"
- Examples: Ship feature, Write blog post, Complete course

### 2 - Areas
Ongoing responsibilities with **no end date**.
- Requires continuous attention
- Has a standard to maintain
- Examples: Health, Finances, Career, Side business

### 3 - Resources
Topics of **ongoing interest** for reference.
- Programming languages
- Tools and frameworks
- Hobbies and interests
- Collected wisdom

### 4 - Archives
**Inactive** items from other categories.
- Completed projects
- Areas you're no longer responsible for
- Resources no longer relevant

---

## The CODE Workflow

### Capture
Save anything that resonates. Don't organize yet - just get it into `0 - Inbox`.

### Organize
During weekly review, move items from Inbox to appropriate PARA folder.

### Distill
Progressively summarize notes:
1. Original content
2. **Bold** the important parts
3. ==Highlight== the essential points
4. Write a summary at the top

### Express
Use your notes to create something: blog posts, code, presentations, etc.

---

## Weekly Review Checklist

- [ ] Empty Inbox - organize or delete everything
- [ ] Review Projects - update status, identify blockers
- [ ] Check Areas - any standards slipping?
- [ ] Archive completed Projects
- [ ] Plan next week's focus
