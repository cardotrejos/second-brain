## Practical Recommendations

### General Usage
- **Think of it as a coworker**, not a tool
- **Trust it more than you think you should** — if you're not occasionally dialing it back, you're not trusting it enough
- **Use voice input** — ramble a 5min braindump, let it turn it into completed tasks
- **Screenshot-to-code** is on a whole new level
- **Use with Obsidian vault** for knowledge management

### Claude Code + Opus 4.5
> "The best AI coding tool in the world. It's indistinguishable from magic."

- **Plan mode** is incredible for complex tasks — drives significantly better performance
- **Compacting no longer kills performance** — small drop-off, but much improved
- **Design capabilities** are now "good enough" (over the AI-slop hump)
- **Best-of-N branching** — have it build multiple approaches, explain tradeoffs, pick the best
- **Try pseudocode** — write pseudocode in your codebase, Opus infers and builds it out

### Claude Agent SDK
> "The best open secret in AI right now"

- **Go deep** — there's a lot of depth, most people only scratch the surface
- **Build something practical** — automate 3 things you frequently do
- **Deploy to cloud** — enables agent swarms working while you sleep (E2B recommended for DX)
- **Agent swarms** — use a `chatroom.md` file for agents to communicate and collaborate
